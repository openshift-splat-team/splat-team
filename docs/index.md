## About

This documentation covers features, processes, and guides for the SPLAT team.

This site follows [Red Hat design principles](https://ux.redhat.com/) and uses [PatternFly design tokens](https://www.patternfly.org/design-foundations/colors/) to maintain consistency with Red Hat's brand and user experience standards.

## Design & Accessibility

Our documentation is built with:

- **Red Hat brand colors** (#CC0000 Red Hat Red, #0066CC PatternFly Blue)
- **Red Hat typography** (Red Hat Text and Red Hat Mono fonts)
- **Accessibility-first approach** following [Red Hat's accessibility standards](https://ux.redhat.com/foundations/accessibility/)
- **PatternFly design tokens** for consistent UI patterns

### Accessibility Features

- Keyboard navigation support
- Screen reader compatibility
- Sufficient color contrast ratios
- Focus indicators for interactive elements
- Skip to content link
- Semantic HTML structure
