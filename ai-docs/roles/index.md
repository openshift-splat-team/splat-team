# Roles

Role definitions and responsibilities for the Splat Team.

## Active Roles

### Superman
All-in-one team member wearing multiple hats (PO, Architect, Dev, QE, SRE, Content Writer).

**See:** [responsibilities.md](responsibilities.md) for hat-switching guide.

### Team Manager
Process improvement and team coordination role.

## Hat-Switching

The superman role switches between different "hats" throughout the workflow:

| Hat | Primary Statuses | Key Responsibilities |
|-----|------------------|---------------------|
| **PO** | `po:triage`, `po:backlog`, `po:accept` | Evaluation, prioritization, acceptance |
| **Architect** | `arch:design`, `arch:plan`, `arch:breakdown` | Design, breakdown, coordination |
| **Dev** | `dev:implement`, `dev:code-review` | Implementation, PR maintenance |
| **QE** | `qe:test-design`, `qe:verify` | Test planning, verification |
| **SRE** | `sre:infra-setup` | Infrastructure provisioning |
| **Content Writer** | `cw:write`, `cw:review` | Documentation |
